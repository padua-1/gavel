# gavel
Every payment gets a ruling
Every payment gets a ruling. Gavel is an AI shopkeeper on Telegram (@GavelShopbot) that builds PayPal orders and subscriptions, screens each payment with a scam-guard before checkout is released, and audits recurring charges. Built for the PayPal AI Hackathon. PayPal sandbox only.## Quick start```bashnpm i grammy express @anthropic-ai/sdk better-sqlite3 dotenvnpm i -D typescript tsx @types/node @types/express @types/better-sqlite3cp .env.example .env        # fill in the valuesnpm run setup:plans         # creates the sandbox subscription plan, paste the id into .envnpm run dev```Dashboard: http://localhost:3000/dashboard/## TODO before submission- Architecture diagram- Sandbox test credentials (buyer account) for judges- How each feature uses PayPal and the AI model- What was built during the hackathon## LicenseMIT
